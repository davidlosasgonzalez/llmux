# OpenCode AGENTS.md — Free Claude Code (Phase 6 / C4)

Copy this file to a project root as `AGENTS.md`, or to
`~/.config/opencode/AGENTS.md` for a global default.

## Models

- Default chat model is whatever `fcc-opencode` injects from FCC `MODEL`
  (currently the C1 winner when configured).
- Fallbacks are handled by the FCC proxy (`MODEL_FALLBACKS`) **before** the
  first SSE byte — do not manually hop models mid-turn unless the user asks.

## When to call the Council MCP (`free-llm-verdict`)

Use the MCP tool `evaluate` (depth `quick`; research `on` when facts matter)
in these cases:

1. Non-trivial planning (new architecture, multi-file redesign, migrations).
2. A bug that already resisted **two** fix attempts in this session.
3. Design review before merging a risky change (auth, data loss, public API).

Prefer the OpenCode command `/council <question>` when available (generated by
`fcc-opencode`). Do **not** call Council on every tool turn.

## Second opinion

For a cheap cross-check without Council, invoke the `@second-opinion` subagent
(also generated by `fcc-opencode`) — it uses a different FCC model family and
is read-only for edits.

## Workspace discipline

- Prefer small diffs; run project checks after edits when available.
- Never force-push `main` / `master`.
- Keep secrets out of commits (`.env`, tokens, keys).
